# AGENTS Instructions

## Scope
These instructions apply to the entire repository.

## Project intent
This repository is dedicated to a Telegram automation system for a daily Food Emulsion & Lipid Processing digest.

## Coding guidelines
- Keep secrets out of source code.
- Use environment variables for all credentials.
- Prefer readable logging and resilient error handling.
- Keep the workflow runnable via GitHub Actions on a schedule and manual trigger.
